# Security

Please don't report a security problem in a public issue.

Use GitHub's private vulnerability reporting instead: the **Report a
vulnerability** button on this repository's **Security** tab. Only the
maintainer sees the report, and it stays private until a fix is out.

A useful report says what is affected (the server, the console, or one of
the agents under `clients/`), how to reproduce it, and which version or
commit you ran.
